Digital Twin Physical AI Robotics

An AI-native industrial robot system that connects real-world observations, task planning, and robot execution through a digital twin.

Our goal: robots that adapt to changing sites, with plans evaluated before deployment and field observations returned to the virtual world.

Research overview

Industrial autonomy built around a changing world

Industrial sites change as people, equipment, and materials move. Rebuilding a simulator and hand-coding robot behavior for every change makes deployment costly. We study a shared environment model that supports perception, agent planning, and execution across different robot bodies.

The deployment problem

Site-specific modeling and control are labor-intensive. Unchecked AI-generated plans can fail when geometry, task rules, or robot capabilities differ from the assumed conditions.

Our systems approach

Combine Real-to-Sim modeling, Prime/Slave agents, deployment interfaces, and persistent scene updates. Simulation and formal methods provide testable boundaries around AI-generated behavior.

HIME scenarios and earlier demonstrations

01 / Real-to-Sim

Real observations into usable simulation scenes

We reconstruct static spaces and object assets for robot simulation. The published single-photograph pipeline now informs work on multi-frame association and measured 3D geometry, so that object identity, scale, and orientation can support scene placement.

  • Video segmentation, point clouds, and camera poses are combined across observations.
  • A simple real scene shows stable 3D boxes qualitatively. A new quantitative accuracy benchmark is still needed.
  • Next: clutter, occlusion, missing points, and reliable placement in more complex scenes.

02 / Prime / Slave Agents

AI-native coordination with Prime and Slave Agents

The Prime Agent interprets work requests, assigns capabilities, and plans across robots. Slave Agents connect the plan to navigation, sensing, and manipulation tools. We combine symbolic planning and verification with environment knowledge and execution feedback.

  • Two AGVs and two arms form a heterogeneous simulation testbed. The object pickup-position calculation has been corrected.
  • API and MCP tools expose scene-graph coordinates and spatial relationships. Current tests mainly cover background structures.
  • Next: connect this knowledge to task planning and measure success, duration, and rule compliance.

03 / Sim-to-Real

Robot interfaces that ground agent plans in action

We build the Slave Agent around Go2, ROS 2/Nav2, sensors, and robot-arm interfaces. Physical demonstrations establish individual capabilities, while simulation provides a controlled setting for preparing navigation and manipulation integration.

  • Go2 motion, mapping, waypoint handling, and arm connectivity have been tested as development modules.
  • An Odin1/MID-360 mount has been designed and fabricated for localization and obstacle sensing. Integrated navigation performance is still to be measured.
  • Next: calibration and integrated robot evaluation. VLA output adaptation and fine-tuning remain in development.

04 / Physical-Virtual Interaction

A digital twin that can track change

Physical-Virtual Interaction returns observations to the digital twin. We separate static geometry from changing object states, preserve object identity and history, and work toward updating simulation and replanning from that evidence.

  • A state-management prototype handles new, moved, unobserved, missing, and rediscovered objects. Five transition tests passed.
  • ROS 2 can trigger a fire event in Isaac Sim, creating a repeatable setting for future inspection tests.
  • Next: observation adapters, coordinate alignment, and continuous USD updates. The full feedback loop remains under integration.
Related demonstrations

Persistent state meets spatial knowledge

DAAAM/Hydra experiments and scene-graph access help define how observations enter the shared model. Current warehouse queries mainly describe background structures; dynamic objects and trajectories still need further integration.

Robot Autonomy / Slave Agent

Mizuki Takahashi

Biography

Mizuki Takahashi is a first-year master's student in the Graduate School of Science and Engineering at Ehime University, specializing in autonomous mobility and manipulation control for AI robots. He develops the Slave Agent that grounds tasks issued by the Prime Agent in the physical world, integrating Unitree Go2 locomotion, SLAM-based localization and mapping, and robot-arm grasping and transport. His next work will integrate SO-101 Arm and back-mounted arm configurations with Go2 for handover and delivery tasks, while fine-tuning Vision-Language-Action models for robot manipulation conditioned on visual observations and language instructions.
