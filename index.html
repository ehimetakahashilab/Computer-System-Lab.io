Research overview

From modeling the site to adapting in the field

Industrial sites change, and not every task can be programmed in advance. We combine environment reconstruction, multi-robot planning, and physical execution. Recent trials extend this work to generating task-specific action programs when available tools are insufficient.

The deployment problem

Site-specific modeling and control are labor-intensive. Unchecked AI-generated plans can fail when geometry, task rules, or robot capabilities differ from the assumed conditions.

Our systems approach

Use a shared environment model to plan and coordinate robots; use execution feedback to refine behavior. Simulation and verification are research foundations, not a guarantee that all field-generated programs have been verified.

FIELD STUDY / MIURA / 4 NOVEMBER 2026

Changing the view to solve an observation problem

At MIURA's Hojo factory, the robot camera could not see the meter window. The agent generated a program using existing robot SDK actions to sit and look upward, then checked the resulting pose and camera image.

  1. Observe the constraint
  2. Generate an action program
  3. Check physical feedback
  4. Next: validate and reuse

An initial step toward adaptive skills, not a new learned motor policy. Meter reading remained unsuccessful; persistent storage and cross-session reuse of this procedure have not been demonstrated.

01 / Real-to-Sim

Real observations into usable simulation scenes

Our single-photograph research provides reusable object assets and plausible initial layouts. Recent work extends the pipeline to factory point clouds, generated equipment models, and automatic scene placement.

  • Factory point clouds and generated equipment models are now used in the scene-building pipeline.
  • The new demonstration shows object placement in a factory scene; it is not a factory-wide accuracy benchmark.
  • Next: recognize specialized equipment and evaluate geometry, scale, and placement across more scenes.

02 / Prime / Slave Agents

AI-native coordination with Prime and Slave Agents

The Prime Agent interprets work requests, assigns capabilities, and plans across robots. Slave Agents connect the plan to navigation, sensing, and manipulation tools. We combine symbolic planning and verification with environment knowledge and execution feedback.

  • Field software now includes session-history search, long-term memory, and skill-authoring functions.
  • A multi-robot MiniGrid testbed separates planning errors from perception and control errors.
  • Next: compare systems with and without memory, skill reuse, and hierarchical agents. Results are not yet available.

03 / Sim-to-Real

Robot interfaces that ground agent plans in action

Physical trials now connect robot management, 3D mapping, navigation, and visual inspection. A reported hardware upgrade to Jetson Thor improved continuous navigation; end-to-end deployment and simulation-to-field alignment still need evaluation.

  • The 10 November report describes stable autonomous travel over approximately 50 m after the hardware upgrade.
  • MIURA field trials exposed navigation timeouts, coordinate mismatches, and camera-view limitations.
  • Next: repeatable inspection completion, enforced stop conditions, and integrated arm control. Grasping is not yet validated.

04 / Physical-Virtual Interaction

A digital twin that can track change

Physical-Virtual Interaction returns observations to the digital twin. We separate static geometry from changing object states, preserve object identity and history, and work toward updating simulation and replanning from that evidence.

  • A state-management prototype handles new, moved, unobserved, missing, and rediscovered objects. Five transition tests passed.
  • ROS 2 can trigger a fire event in Isaac Sim, creating a repeatable setting for future inspection tests.
  • Next: continuous observation ingestion, coordinate alignment, and scene updates. Continuous DAAAM/Hydra extraction remains unresolved in the reviewed reports.
Related demonstrations

Persistent state meets spatial knowledge

DAAAM/Hydra experiments and scene-graph access help define how observations enter the shared model. Current warehouse queries mainly describe background structures; dynamic objects and trajectories still need further integration.

What the evidence supports

We report component tests and simulation results separately from physical deployment. No overall completion percentage or industrial safety guarantee is claimed.

Mizuki Takahashi

Biography

Mizuki Takahashi is a first-year master's student in the Graduate School of Science and Engineering at Ehime University, specializing in autonomous mobility and manipulation control for AI robots. He develops the Slave Agent that grounds tasks issued by the Prime Agent in the physical world, integrating Unitree Go2 locomotion, SLAM-based localization and mapping, and robot-arm grasping and transport.
